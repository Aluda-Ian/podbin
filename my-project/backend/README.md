# Backend Application

This directory contains the backend application for the project.

## Setup Instructions

1. **Install Dependencies**: 
   Make sure you have Python installed. Navigate to the `backend` directory and run:
   ```
   pip install -r requirements.txt
   ```

2. **Run the Application**: 
   To start the backend server, run:
   ```
   python main.py
   ```

## Usage

The backend application serves as the API for the frontend. It handles requests and responses, and interacts with the database if applicable.

## Directory Structure

- `main.py`: Entry point for the backend application.
- `requirements.txt`: Lists the required Python packages.
